# Salman A — Graphic, Brand & UI/UX Designer Portfolio

Dark editorial portfolio showcasing **41 complete case studies** across **Logo & Brand Identity (14)**, **Brand Starter Packs (3)**, **Mobile & SaaS UI/UX (11)**, and **Conversion Web Design (13)**.

## Live Site
- **Vercel:** `https://salmancz-designer.vercel.app`
- **GitHub:** `https://github.com/salmancz/salmancz-designer`

## Structure
```
index.html         Main portfolio (Flagship, Logo & Brand gallery, UI/UX & Web gallery, Capabilities, About, Contact)
styles.css         Dark editorial design system, filterable catalog grids, lightbox modal
case-study.css     Individual case study layout, visual plates, and archive strip
script.js          IntersectionObserver reveals, category filtering, full-screen image lightbox
work/*.html        41 dedicated project case study pages with all project visuals
assets/img/        220+ local WebP/PNG/JPG brand, packaging, and UI visuals
```
