Portfolio / UI/UX / Cryptedge
App & Product UI/UX · Crypto/Fintech

A unified trading dashboard that turns multi-asset complexity into clarity.

Cryptedge is a next-generation investment platform where users trade cryptocurrencies, stocks, bonds, and ETFs in one integrated experience. I designed the UI/UX, building a single control center that makes complex financial data readable for first-time investors and experienced traders alike.

RoleProduct UI/UX Designer
Year2025
DeliverablesUser Research, Wireframing, Figma UI Kit, Prototyping
IndustryCrypto/Fintech
01 · The Brief

The objective

Cryptedge lets people trade cryptocurrencies, stocks, bonds, and ETFs inside one platform, so the interface had to carry a lot of financial data without overwhelming anyone. The goal was a unified dashboard that merged multi-asset tracking, visualized real-time data in a digestible way, surfaced user insights without clutter, and stayed seamless across web and mobile trading.

  • User Flows & Wireframes
  • High-Fidelity UI
  • Figma Design System
  • Interactive Prototype
02 · Craft & Visual System

The approach

The design made financial complexity accessible. We built a single control center with toggles between asset classes, added interactive charts and portfolio health scoring, and embedded AI-powered recommendations alongside gamification features. Clickable prototypes were built for testing, and the full interface was designed for dark mode compatibility from the start.

03 · Execution & Deliverables

Process and outcomes

The work ran across six phases: discovery and strategy, information architecture, a UI design system, smart engagement, prototyping and testing, then handoff and support. User personas spanned first-time investors to experienced traders, and the dashboard was organized around their goals of tracking, buying and selling, and learning. Color-coded performance indicators, reusable components, and milestone and streak-based engagement reduced cognitive overload, sped up asset-class switching, and built user confidence during trades. Delivery included a modular UI kit, interaction specifications, and post-handoff support. Tools used were Figma and Miro.
